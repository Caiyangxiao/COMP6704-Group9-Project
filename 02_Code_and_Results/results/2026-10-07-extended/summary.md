# 扩展实验结果（2026-10-07）

三种原有算法；24 个配对合成实例；360 次计时；68 次正则化拟合。全部达到 R≤10⁻⁶。同一问题的相对目标差最大为 8.61×10⁻¹¹。

## 相关性与时间（ms）

| ρ | ISTA | FISTA | CD |
| --- | ---: | ---: | ---: |
| 0 | 0.360 ± 0.010 | 0.521 ± 0.043 | 0.762 ± 0.107 |
| 0.5 | 3.236 ± 0.223 | 3.782 ± 0.208 | 3.318 ± 0.321 |
| 0.9 | 21.667 ± 1.026 | 16.876 ± 1.160 | 16.443 ± 1.622 |
| 0.99 | 154.599 ± 10.491 | 19.862 ± 18.153 | 62.507 ± 8.707 |

μ±s 为三个实例计时中位数的均值与样本标准差；每个实例计时五次。ρ=0.99 时 FISTA 平均最快，但跨实例差异较大。ρ=0.5 的 ISTA 与 CD 很接近，不作精确排序。

## 展示图与讲解顺序

1. 先用二维轨迹解释向量更新、加速外推与逐坐标更新；相同轮数不等于相同计算量。
2. 相关性图回答“为什么原来的 FISTA 没有更快，而高相关情况下更快？”完整 Gram 条件数随 ρ 上升，但活动集也变，不能把耗时全部归因于一个数。
3. 规模图展示 CD 的四个 sweeps 不变，但每轮需访问更多坐标；向量方法在这组独立特征设计里更快。
4. 系数路径展示随 λ 增大变量退出以及 s3 的非单调幅度变化；训练/测试 MSE 都是真实固定划分结果，不用于测试集调参。
